# Roadmap

Goal: a playtest with 3–5 players, then a release on itch.io.
Tick items off as they land. Tom decides the order inside each phase.

## 1. Ready to playtest
- [ ] Tom plays it through start to win and notes anything that feels off
      (holding, throwing, clutter, gate pacing, the hunt).
- [ ] Sound check by ear: squeaks audible and easy to place, menu chimes, clacks.
- [ ] Squeak and ping sound pass (from that check).
- [x] First-minute lesson: teach grab, throw, ping and catch without text walls
      (the landing room, `tutorial.gd`).
- [ ] Try the untested edge cases: wedged doorway, stacked climbing, creatures
      cornered behind heavy furniture, wardrobe swept through clutter.
- [ ] Smoothness on a real display (V-Sync, frame pacing).

## 2. Playtest
- [ ] Download Godot export templates (Tom), then a Windows export.
- [ ] A short list of things to watch and ask (did clues lead you, where did
      you get stuck, what made you smile).
- [ ] 3–5 players; write up what came back.

## 3. After the playtest
- [ ] Fix what the playtest found.
- [ ] More life in the creatures beyond the eyes (squash/stretch, lean,
      startled jump), if the eyes weren't enough.
- [ ] Design call: tip-but-not-lift heavy things (wardrobe gate needs an exception).
- [ ] Clue quality: do tells and ping beat checking every bin?
- [ ] Trapdoor under the rug opens to a hidden space with something to find
      (Grace's idea).

## 4. itch release
- [ ] Web build test; decide Windows only or Windows + web.
- [ ] Final settings defaults and a quick performance pass (`bench_gpu`).
- [ ] Credits and licences (Coiny font, any sounds).
- [ ] itch page: screenshots, a short GIF, description, price (free / pay what you want).
- [ ] Release.
